What the actual evaluation would measure

Tracking uses planar velocity RMSE against a fixed command schedule. Traversal success requires reaching the goal within the time limit without falling. Fall rate is the fraction of evaluation episodes with a fall. Every checkpoint receives the same terrain and start conditions.

How to read this preview

The same synthetic curves are reused for all three bodies to demonstrate the layout, not rank their performance. The shaded bands are illustrative, not confidence intervals. Actual evaluation would include each saved initial policy and repeated episodes per checkpoint.
