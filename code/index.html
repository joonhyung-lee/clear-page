Reproduce a planning example

Python 3.11 · CPU
Terminal
unzip clear-source.zip
unzip clear-pretrained.zip
cd clear
python tools/link_checkpoints.py
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install "torch>=2.7" numpy einops pyyaml scipy

python run.py plan maze \
  --checkpoint ../checkpoints/maze/reference/seed0/clear.pt \
  --input experiments/exp3/data/example_g1.json \
  --out outputs/reproduction/plan.json --device cpu

The command produces a planned route. Illustrative method views and recorded controller examples accompany the source below.
